## 概要

Hooksやトリガー、Computer Use、Copilot Studio Kitなど、今後より高度なエージェント開発を進める上で使える道具を紹介する解説の枠です。Labはありません。

## 学習目標

- 基礎①〜⑧で扱わなかった、エージェント開発を広げる機能と道具を知る。
- それぞれの機能が、どのような場面で役に立つかを理解する。

## 解説の内容

| 機能・道具 | できること |
| --- | --- |
| Hooks（プレビュー） | セッションの開始、ツールの実行前、エラーの発生など、エージェントの動作の決まった時点で、ワークフローを毎回自動で実行します。エージェントが必要と判断したときだけ動くツールと違い、イベントが起きるたびに必ず動きます。 |
| トリガー（プレビュー） | メールの受信、SharePointへの項目の追加、決めた時刻など、つないだサービスで起きたイベントをきっかけに、エージェントを自律的に動かします。 |
| Computer Use | Windowsのコンピューター上で、Webサイトやデスクトップアプリのボタンやメニューを選び、文字を入力して作業を進めます。APIで接続できないシステムの操作にも使えます。 |
| Copilot Studio Kit | Power CATが作成・提供している、エージェントの開発、ガバナンス、テスト、改善のためのツールキットです。テストセットを使った一括テストや、組織内のエージェントの一覧（Agent Inventory）などの機能があります。 |

> [!NOTE]
> Computer Useは、Microsoft Copilotハーネスでは「計画済み」の機能です。現在は標準ハーネスで利用できます。

## まとめ

- Hooksとトリガーを使うと、会話の外のイベントやエージェントの動作の節目に合わせて、処理を確実に動かせます。
- Computer Useを使うと、APIがないシステムの画面操作もエージェントに任せられます。
- Copilot Studio Kitを使うと、エージェントのテストや管理をまとめて進められます。
