# Microsoft 365 Copilot 利用・ライセンス申請ガイド

## この資料について

この資料はハンズオン用に作成した架空の社内ルールです。実在する企業の規程や Microsoft のライセンス条件ではありません。

- 文書 ID：COPILOT-001
- 版：1.0
- 作成日：2026 年 11 月 16 日
- 管理部署：IT 部門 ライセンス管理窓口
- 対象：社員が業務用の組織アカウントで利用する Microsoft 365 Copilot

Microsoft の製品機能・利用条件・ライセンスの種類・一般的な確認方法は、最新の Microsoft 公式情報を確認してください。この資料は社内の申請・承認・費用負担・問い合わせ先を定めます。公式の利用条件を満たしているだけでは、社内での利用承認が完了したことにはなりません。

## 1. 利用対象と申請資格

業務で Microsoft 365 Copilot を利用したい社員は、所属部署を問わず申請できます。申請資格があることは、利用承認やライセンスの割り当てを保証するものではありません。

社員以外の業務委託者・ゲストは、この通常申請の対象外です。利用が必要な場合は、受け入れ部署から IT 部門 ライセンス管理窓口へ個別に相談してください。

個人アカウントで利用する Microsoft Copilot や GitHub Copilot は、この申請の対象外です。Microsoft 365 Copilot Chat の利用条件は公式情報を確認し、Microsoft 365 Copilot の申請と混同しないでください。

## 2. すでに利用できるかを確認する

利用者は組織アカウントでサインインし、Microsoft 公式の案内に沿って自分のライセンス情報を確認します。

- 割り当て済みと確認でき、利用できている場合：追加申請は不要です。
- 割り当て済みと確認できるが、アプリで表示されない・利用できない場合：新規申請ではなく、IT 部門 ヘルプデスクへトラブルとして問い合わせます。
- 未割り当てと確認でき、利用を希望する場合：第 3 章の手順で申請します。
- 割り当て状況を確認できない場合：新規申請を決めつけず、まず IT 部門 ライセンス管理窓口へ確認を依頼します。

アプリに Copilot が表示されないことだけで、未割り当てと判断してはいけません。この資料から個人の割り当て状況を確認することもできません。

## 3. 新規申請の手順

1. 社内サービスデスクの「Microsoft 365 Copilot 利用申請」を使用します。
2. 申請には、所属部署・利用目的・想定する利用業務・希望する利用開始日を記載します。申請者の本人情報は社内サービスデスクの認証情報で扱うため、案内用エージェントへのメールアドレスの入力は不要です。
3. 所属長が業務上の必要性と費用負担を確認し、承認または差し戻しを行います。
4. 所属長の承認後、IT 部門 ライセンス管理窓口が公式の利用条件、契約、ライセンス在庫を確認します。
5. 条件が整った場合、IT 部門が割り当てを行い、社内サービスデスクで申請者へ通知します。

この演習では社内サービスデスクの実 URL は提供しません。案内用エージェントは申請先の名称を案内し、存在しない URL を作らないでください。申請画面が見つからない場合は、IT 部門 ライセンス管理窓口へ問い合わせます。

## 4. 承認・在庫・利用開始日の扱い

- 所属長の承認前に、ライセンスを割り当ててはいけません。
- Microsoft 365 管理者であっても、申請・承認を省略してはいけません。
- 在庫があることだけでは、割り当ての条件を満たしません。
- 在庫がない場合は、IT 部門が購入または割り当て調整の可否を確認します。利用者が独自に購入する必要はありません。
- 希望する利用開始日は希望であり、確約ではありません。承認や購入が必要なため、この資料では完了日・処理日数を定めていません。

## 5. 費用と契約

ライセンス費用は、原則として利用者の所属部署が負担します。社員個人での支払いや立替購入は行いません。

具体的な単価、契約期間、契約中のプラン、追加購入の可否は、この資料には掲載しません。IT 部門 ライセンス管理窓口へ確認してください。Microsoft の公開価格を、そのまま社内の契約価格として案内してはいけません。

## 6. 異動・利用終了

部署異動時は、継続利用の必要性と新しい所属部署の費用負担について、新しい所属長と IT 部門 ライセンス管理窓口へ確認します。

利用を終了する場合は、社内サービスデスクから IT 部門 ライセンス管理窓口へ解除を依頼します。割り当てや解除は IT 部門が行い、案内用エージェントは実行しません。

## 7. 問い合わせ先

| 問い合わせ内容 | 窓口 |
| --- | --- |
| 申請方法・申請資格・割り当て状況が不明 | IT 部門 ライセンス管理窓口 |
| 契約・費用・在庫・利用開始見込み | IT 部門 ライセンス管理窓口 |
| 業務上の必要性・承認・部署の費用負担 | 所属長 |
| 割り当て済みだが表示されない、エラーで利用できない | IT 部門 ヘルプデスク |
| 業務委託者・ゲストの利用相談 | 受け入れ部署から IT 部門 ライセンス管理窓口へ相談 |

各窓口への連絡は社内サービスデスクを使用します。メールアドレス・電話番号・実 URL は、この演習では設定していません。

## 8. 案内用エージェントの対応範囲

案内用エージェントは、公式の製品情報とこの社内ルールを区別し、該当する根拠を示して案内します。

- 個人のライセンス割り当て、申請状況、承認状況、在庫、契約価格を推測しません。
- パスワード、認証コード、機密ファイルの提出を求めません。
- この演習では申請の登録・承認・購入・割り当て・解除・通知送信を実行しません。
- 実行していない処理を「受付済み」「承認済み」「割り当て済み」と案内しません。
- この資料に記載がない社内ルールや例外は作らず、IT 部門 ライセンス管理窓口への確認を案内します。
